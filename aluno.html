🎨 Atividade Prática — Blog da Turma

Você vai construir a página de um blog escolar em duas partes: primeiro o HTML, depois um arquivo CSS externo chamado estilo.css. Cada etapa mostra apenas o resultado esperado na tela — o código é você quem deduz.

🧱 HTML puro 🎨 CSS externo (estilo.css) 📐 9 etapas em 3 fases ✅ Validação em checklist 📤 Exportar progresso

🎯 O que você vai construir

Uma página chamada Blog da Turma, com cabeçalho, menu de navegação com três âncoras, três postagens, uma tabela de agenda e um formulário de contato. O HTML precisa estar correto antes de você começar a pensar no CSS — e o CSS vem em um arquivo separado, ligado ao HTML.

📋 Regras fundamentais:
  • Você vai criar dois arquivos: index.html e estilo.css, na mesma pasta.
  • Nenhum CSS dentro do HTML: sem atributo style, sem tag <style>.
  • Nenhum JavaScript.
  • Não use <section>, <article> nem <div> — use os mesmos elementos do exercício anterior.
  • O arquivo CSS é ligado ao HTML pela tag <link rel="stylesheet" href="estilo.css">, dentro do <head>.
⚠️ Como esta atividade funciona: na aba Fase HTML você vê apenas o resultado esperado de cada etapa. Na aba Fase CSS, cada etapa mostra o mesmo HTML antes e depois de você aplicar o CSS — com uma legenda dizendo o que mudou na tela, não o código. Você decide quais propriedades usar para produzir aquela mudança.

🧱 Fase 1 — Construir o HTML

Antes de qualquer CSS. Em cada etapa, você vê o resultado esperado na tela e lê o texto que deve aparecer. O HTML que produz esse resultado é você quem escreve.

💡 Como usar: abra seu index.html no navegador ao lado desta aba. A cada etapa, compare a sua tela com a prévia. Se estiver diferente, ajuste o HTML antes de seguir.

Estrutura inicial e cabeçalho

Crie index.html. Defina lang="pt-BR", charset="UTF-8" e o título da aba como Blog da Turma. No body, comece com um <h1> com o texto Blog da Turma e um <p> com o subtítulo Notícias, projetos e ideias dos estudantes.

Por enquanto, não adicione o <link> do CSS — isso fica para a Fase 2.

index.html — sem CSS
O que observar: o navegador aplica a fonte padrão e o h1 aparece grande e em negrito, o p logo abaixo. Nada de cor ou alinhamento especial.

Menu de navegação com três âncoras

Logo depois do parágrafo, crie um <nav> com três links separados pelo caractere |:

  • Postagens → aponta para #postagens
  • Agenda → aponta para #agenda
  • Contato → aponta para #contato

Depois do </nav>, insira uma linha horizontal <hr>.

index.html — sem CSS
O que observar: os links ficam na mesma linha, em azul e sublinhados. O | é texto comum entre eles. O <hr> desenha uma linha fina cinza.

Postagens, agenda e formulário

Complete o restante do HTML. Use <h2 id="…"> antes de cada bloco (postagens, agenda, contato), <hr> separando os blocos, e os dados exatos abaixo.

🎨 Fase 2 — Aplicar o CSS externo

Agora você cria o arquivo estilo.css na mesma pasta do index.html e o liga ao HTML. Cada etapa mostra o mesmo HTML da etapa anterior já com o CSS aplicado, mais uma legenda dizendo o que mudou. O código é você quem escreve.

⚠️ Antes de começar: no <head> do seu HTML, adicione <link rel="stylesheet" href="estilo.css">. Sem isso, o navegador não carrega o CSS. Se a sua página continuar "crua", quase sempre é porque o <link> está faltando ou o nome do arquivo está diferente.
💡 Como usar: escreva as regras aos poucos. Salve o estilo.css, recarregue o index.html no navegador e compare com a prévia desta etapa. Se ainda não bateu, veja a legenda: ela diz o que mudou, não como fazer.

Fundo e tipografia da página

Comece pelo body. Aplique:

  • uma cor de fundo clara (aqui usamos um bege suave #f8f5f0);
  • uma família de fonte sem serifa (ex.: Arial, Verdana ou a família padrão sans-serif);
  • uma cor de texto escura (ex.: #1f2937);
  • um pouco de espaço interno para o conteúdo não colar na borda (ex.: padding: 24px);
  • uma altura de linha confortável (ex.: line-height: 1.6).
index.html + estilo.css — após etapa 4
O que mudou: o fundo da página deixou de ser branco. A fonte mudou de "Times" para uma sem serifa. O texto está com espaçamento mais confortável. Nenhuma cor forte ainda — o objetivo aqui é só a base.

Cores do título, do menu e dos links

Agora dê identidade visual ao topo da página:

  • o h1 fica com uma cor de destaque (ex.: #0d9488) e centralizado;
  • o nav ganha um fundo escuro (ex.: #0f172a) e espaço interno;
  • os links do menu perdem o sublinhado, ficam brancos e com espaçamento entre si.
index.html + estilo.css — após etapa 5
O que mudou: o título ficou colorido e centralizado. O menu virou uma faixa escura, com links brancos e sem sublinhado. Os links ainda estão lado a lado porque o HTML já era nav + a inline. A barra vertical | entre eles continua visível — vamos resolver isso na próxima fase.

Espaçamento, linhas e tabela

Deixe o conteúdo respirar:

  • dê margem abaixo dos parágrafos;
  • esconda o <hr> trocando a borda por uma linha clara (ou retire a borda e adicione border-top suave);
  • na tabela, faça as células terem espaço interno, o cabeçalho ter fundo colorido e o texto das células ficar alinhado à esquerda.
index.html + estilo.css — após etapa 6
O que mudou: os parágrafos estão mais separados. As linhas horizontais ficaram mais discretas. A tabela ganhou cabeçalho com fundo colorido e células com respiro interno — sem perder a grade do border="1".

Formulário em "cartão"

Transforme o formulário em um bloco visualmente destacado:

  • fundo branco, borda suave e cantos arredondados;
  • espaço interno generoso;
  • largura máxima de 420px e centralizado na página;
  • uma sombra suave para dar profundidade.

Não altere o HTML do formulário — tudo isso é feito com o seletor form.

index.html + estilo.css — após etapa 7
O que mudou: o formulário agora parece um cartão separado do resto da página. Os campos continuam com aparência padrão do navegador — não estamos estilizando input nem select ainda. O botão também continua padrão.

Menu em linha e botão estilizado

Duas mudanças pontuais que exigem mais cuidado:

  • no nav, faça os links ficarem distribuídos horizontalmente com espaço entre eles. Você pode usar display: flex + gap no nav, e esconder o texto do separador | reduzindo o font-size ou envolvendo-o em algo que o CSS esconda — mas sem alterar o HTML;
  • no button, aplique fundo colorido, texto branco, cantos arredondados, espaço interno e remova a borda padrão.
index.html + estilo.css — após etapa 8
O que mudou: os links do menu agora estão alinhados como uma barra, com espaçamento uniforme. O botão do formulário ficou colorido e arredondado. O separador | entre os links praticamente sumiu visualmente.

Acabamento: sombra no menu e espaçamento dos títulos

Últimos ajustes de polimento:

  • uma sombra suave no nav para destacá-lo do fundo;
  • margem superior nos h2 para separar visualmente os blocos;
  • um h2 com cor de destaque parecida com a do h1.
index.html + estilo.css — após etapa 9 (resultado final)
O que mudou: o menu ganhou profundidade com a sombra. Os títulos das seções estão mais separados e com cor. A página inteira tem agora uma identidade visual coerente — e você chegou a ela sem copiar CSS pronto, deduzindo a partir da descrição e da prévia.

🧪 Testes

Faça os testes na ordem, com o index.html aberto no navegador.

1
O CSS está carregando?

Se a página estiver com fundo branco, fonte "Times" e links azuis sublinhados, o <link rel="stylesheet" href="estilo.css"> não está funcionando. Verifique se o nome do arquivo é exatamente estilo.css e se ele está na mesma pasta do index.html.

2
Navegação — Postagens

Clique em Postagens no menu. A página deve rolar até o bloco de postagens. A URL termina com #postagens.

3
Navegação — Agenda e Contato

Repita para Agenda (#agenda) e Contato (#contato). Se algum link não rolar, verifique se o id correspondente está no h2 certo.

4
Menu como barra

Os três links do menu devem aparecer lado a lado, com espaço entre eles, sem sublinhado e em cor contrastante com o fundo escuro. Se ainda houver | visível entre eles, volte à etapa 8 — a legenda explica o que deveria ter mudado.

5
Formulário como cartão

O formulário deve aparecer como um bloco branco separado do resto, com cantos arredondados e sombra suave. Se estiver "colado" no fundo, o seletor form pode não ter sido aplicado corretamente.

6
Envio do formulário

Preencha o nome, escolha um assunto e clique em Enviar mensagem. Com internet, o httpbin responde com um JSON contendo "form": {"nome": "...", "assunto": "..."}. Sem internet, o navegador mostra erro de destino — o que já prova que o formulário tentou enviar.

7
Nenhum CSS no HTML

Abra o index.html no editor e procure por style= e <style>. Não deve haver nenhum. Todo o CSS deve estar no estilo.css.

8
Nenhum JavaScript

Procure por <script> no index.html. Não deve existir nenhum.

⚠️ Lembrete: o httpbin.org é um serviço público de testes. Use apenas dados fictícios como "Ana" ou "teste@exemplo.com". Nunca digite dados reais.
